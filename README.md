# Lumio — Multi-Game Android App (Kotlin)

Pure Kotlin Android app. No npm. No Node.js. No Expo.

## Build
GitHub Actions builds automatically on every push to `main`.
Go to Actions tab → Download `lumio-kotlin-apk` artifact → Install on Android phone.

## Local build (optional)
Requires Java 17 only.
```
./gradlew assembleDebug
```
APK output: `app/build/outputs/apk/debug/app-debug.apk`

## Games
Tic Tac Toe · Chess · Ludo · Air Hockey · 8 Ball Pool · Carrom
Water Sort · Block Puzzle · Hexa Fall · Tile Dom · Dice Dom · Crazy Knife
